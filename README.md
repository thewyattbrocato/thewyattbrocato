## Selected work

- **[AI Deal Finder][deal-finder-live]**: search store pages that were checked ahead of time. Each result shows the shelf price, a plain decision, and a coupon only when that product's own page printed one. It runs in the browser, and the [source][deal-finder] is public.
- **[csm-kit][csm-kit]**: an offline Node.js CLI that turns CRM, ticket, and usage exports into renewal, handoff, and QBR briefs. Every factual line cites its source row. Read a [generated renewal brief][csm-output] or try the [interactive demo][csm-demo].
- **[Scam First Aid][scam-first-aid]**: free, private help after a scam, with ordered steps, exact words to say, and family conversation scripts. Nothing typed leaves the browser. Its [public repository][scam-first-aid-repo] holds the reviewed static site, not the source.
- **[Leverage Library][leverage-library]**: a sourced, cross-book idea library. Each idea is attributed, paraphrased, and flagged for confidence. Its [public repository][leverage-library-repo] holds the reviewed static site, not the source.
- **AI Leverage Field Guide**: interactive, role-based workflow guides with local progress tracking and explicit human-review boundaries. Its [public repository][field-guide-repo] holds the reviewed static site; a live link is not yet verified.
