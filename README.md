# Wyatt Brocato

**A PM testing AI on real work.**

I build practical AI work systems for experienced professionals: rough inputs become work you can stand behind, with context, risk, and approval staying human.

## Start here

- **[AI Deal Finder][deal-finder-live]**: search store pages that were checked
  ahead of time. Each result shows the shelf price, a plain decision, and a
  coupon only when that product's own page printed one. It runs in the
  browser, and the [source][deal-finder] is public.
- **[csm-kit][csm-kit]**: an offline Node.js CLI that turns CRM, ticket, and
  usage exports into renewal, handoff, and QBR briefs. Every factual line
  cites its source row. Read a [generated renewal brief][csm-output] or try
  the [interactive demo][csm-demo].

## Selected work

- **[Scam First Aid][scam-first-aid]**: free, private help after a scam, with
  ordered steps, exact words to say, and family conversation scripts. Nothing
  typed leaves the browser. Live; its [public repository][scam-first-aid-repo]
  holds the reviewed static site, not the source.
- **[Leverage Library][leverage-library]**: a sourced, cross-book idea
  library. Each idea is attributed, paraphrased, and flagged for confidence.
  Live; its [public repository][leverage-library-repo] holds the reviewed
  static site, not the source.
- **[5-Task Swap][task-swap]**: a no-login diagnostic that turns one recurring
  task into an explained fit assessment and a bounded 15-minute experiment.
  Live; source is not public.
- **AI Leverage Field Guide**: interactive, role-based workflow guides with
  local progress tracking and explicit human-review boundaries. Its
  [public repository][field-guide-repo] holds the reviewed static site; a
  live link is not yet verified.

## Now

- **Building:** AI Deal Finder. The live tool works today on stored, checked
  pages. Its agent skill, which returns one buy, wait, verify, or abstain
  decision, is still in validation, and no acceptance gate has passed yet.
- **Writing:** The AI Business Playbook, a live newsletter. Each issue is a
  workflow, its judgment check, and one small experiment.
  [Subscribe on the signup page][subscribe].
- **Focus:** practical systems for Customer Success, workflow design, and
  evidence-led decisions.
- **Point of view:** use automation for structure and repetition; keep
  context, risk, and approval human. Cite the source or mark the gap.
